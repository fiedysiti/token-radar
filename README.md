A token launch radar over a sealed DefiLlama snapshot: it finds the protocols that still record no token, ranks them by an implied launch value derived from their own figures (TVL, seven-day growth, time running with no token), and hands the reader a dashboard with a board, a detail view per protocol, and concrete farm steps with costs and durations.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
